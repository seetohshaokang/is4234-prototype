# NimbusWatch Security Statement
*Website · Dated 2017-12-01*

NimbusWatch takes the security of its systems and customer data seriously.
The following statements describe our current security practices.

Admin accounts in our systems are limited to a small fraction of staff,
remote access is restricted to managed corporate devices, and shared accounts
are not permitted `(SCC-01 v1)`.

All applicable systems enforce a password policy requiring complexity and
regular rotation, and no credentials are stored in source code repositories
`(SCC-02 v1)`.

Every software release goes through automated security scanning and dependency
checks before deployment `(SCC-03 v1)`.

Production changes follow a formal review and approval process, with all
changes monitored and logged `(SCC-05 v1)`.
